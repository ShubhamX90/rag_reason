# Legacies

This directory contains older, superseded, intermediate, or reviewer-noisy material that was moved out of the main tree during repo curation.

Nothing here was deleted. The goal is to keep the main repository focused on the latest runnable pipeline, latest canonical datasets, latest benchmark outputs, latest val ceiling outputs, and the current human-eval package.

## What Lives Here

- Older docs, changelogs, and fix notes
- Superseded experimental configs
- Older prep/output trees that were replaced by canonical `inputs/` and `outputs/benchmark_local_committee_3judge/` paths
- Older runner helpers that no longer represent the current workflow
- Scheduler manifests, transient logs, caches, and temporary artifacts
- Misc generated clutter such as `__pycache__`, `.pyc`, and `.DS_Store`

## Removal Policy

If you want a clean submission-oriented repo, you can package the repository without this directory after confirming you no longer need the archived material.
