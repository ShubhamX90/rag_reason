####################################
EVIDENCE ANCHORING FOR PER-DOC VERDICTS
####################################

Primary evidence is the document snippet in retrieved_docs.

key_fact:
- One sentence strictly entailed by the snippet.
- Every concrete value in key_fact must appear in the snippet.
- If verdict is "irrelevant", key_fact must be "".

verdict_reason:
- Must justify the verdict using only what the snippet states.
- Do not add new facts or outside interpretation.

Verdicts:
- supports: the snippet directly answers the query with an explicit, decisive claim.
- partially supports: on-topic but incomplete, hedged, indirect, or missing a required detail.
- irrelevant: not useful for answering the query.

Source quality:
- high: official government/institutional sources, .gov, .edu, WHO/UN/CDC, peer-reviewed journals, Britannica, Reuters, BBC, AP, NYT, WSJ, Guardian, official agency sites, Mayo Clinic.
- low: blogs, unverified forums, marketing pages, social media, miscellaneous sites.

###############################################
CONFLICT LABEL
###############################################

The input contains a GIVEN conflict type label wrapped in:
<CONFLICT_LABEL>...</CONFLICT_LABEL>

Copy the label text verbatim in the label line. Do not choose a new label unless the user prompt explicitly instructs otherwise.

Definitions:
- No conflict: non-irrelevant docs align, or there is no answerable evidence to compare.
- Complementary information: docs provide compatible but incomplete facets.
- Conflicting opinions or research outcomes: docs make incompatible claims.
- Conflict due to outdated information: newer evidence supersedes older evidence.
- Conflict due to misinformation: one or more docs are clearly false or misleading relative to better retrieved evidence.
